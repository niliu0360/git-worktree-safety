# 安全边界

## 本 Skill 能证明什么

- 当前 Git 元数据中是否存在 dirty、detached、locked、未完成操作、未合并分支或远端跟踪分叉。
- 在支持的 Git 版本中，source 与 target 的只读 merge-tree 检查是否报告冲突。
- 某个本地分支是否能从目标分支历史中到达。

## 本 Skill不能证明什么

- 代码逻辑正确；
- 测试已经覆盖全部需求；
- PR 已获得批准；
- 远端状态是实时的；
- 没有其他进程或 AI 会话占用目录；
- 清理 worktree 不会影响部署、演示或人工约定；
- 推送不会被服务端策略拒绝。

## 失败原则

- 读不到状态：返回 `INVALID` 或阻止，不猜测。
- merge-tree 不可用：返回警告，不声称无冲突。
- remote-tracking ref 不存在：阻止推送，合并检查按严格参数决定警告或阻止。
- 删除条件不确定：`REVIEW_REQUIRED`，不生成自动执行行为。
